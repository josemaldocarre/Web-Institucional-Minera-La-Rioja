# Web Institucional de Minería - La Rioja


Plataforma web institucional orientada a:

- Transparencia
- Gestión de trámites
- Educación para la ciudadanía

## 🧠 Objetivo

Construir una experiencia moderna que funcione como una plataforma digital institucional.

## ⚙️ Stack

- React
- TypeScript
- Vite
- SASS

## 🚀 Setup

```bash
npm install
npm run dev
```

## 📁 Estructura

El proyecto está organizado de forma modular y escalable:

- components → UI reutilizable
- layouts → estructura global
- pages → páginas principales
- modules → secciones del sistema
- services → lógica de datos
- data → mocks
- styles → sistema de diseño
- i18n → traducciones
